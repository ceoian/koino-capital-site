# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Mission

Marketing site for Koino Capital under the `ceoian` org — distinct from the koinod-owned `koino-storefront`. Driven by autonomous CMO agents from the OCI fleet. Content is generated, published, and iterated without per-post human approval.

## Stack

Static HTML + JS, Vercel-deployed.

## First-time orientation

Before doing substantive work in this repo, read in order:

1. **[ceoian/agent-learnings/CLAUDE.md](https://github.com/ceoian/agent-learnings/blob/main/CLAUDE.md)** — org-wide operating principles.
2. **[ceoian/agent-learnings/insights/agent-vs-human-sdr-honest-delta.md](https://github.com/ceoian/agent-learnings/blob/main/insights/agent-vs-human-sdr-honest-delta.md)** — the autonomous-CMO honest delta.
3. **This repo's `README.md`** — what it is and how to run it.

## Principles

- Match the koinod-owned koino-storefront's brand voice — same company, different surface.
- Don't ship copy without running it through `mkt-copywriting` or `mkt-copy-editing` skills.

## Don'ts

- Don't change the domain config without coordinating with whoever owns the DNS.
- Don't conflate this with the koinod-owned koino-storefront — they're siblings, not the same.
