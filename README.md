# koino-capital-site

Marketing site for **Koino Capital** — the autonomous-CMO experiment branch (this is the `ceoian` org's site, distinct from the koinod-owned `koino-storefront` which is the main `koino.capital` storefront).

## Status

Live site driven by autonomous CMO agents from the OCI fleet. Content is generated, published, and iterated by agents without per-post human approval.

## Structure

Static HTML + JS, deployed via Vercel. See `index.html` for the entry point.
